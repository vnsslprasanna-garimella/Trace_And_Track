# Official Tech Stack

When working on the Trace and Track application, strictly adhere to the following technology stack. Do not introduce alternative technologies for these layers unless explicitly approved by the user.

## Mobile App
- **Mobile**: React Native
- **Mobile framework**: Expo Development Build
- **Location**: Expo Location / Native APIs
- **Maps**: Leaflet + OpenStreetMap
- **Battery**: Native/Expo Battery APIs

## Web Dashboard
- **Dashboard**: React.js
- **UI**: Tailwind CSS

## Backend
- **Backend**: Node.js + Express.js
- **Real-time**: Socket.IO
- **Database**: PostgreSQL
- **Geospatial**: PostGIS
- **Cache**: Redis (optional)
- **Authentication**: JWT + bcrypt/Argon2
- **Deployment**: Vercel + Render initially

## General
- **Version control**: Git + GitHub
